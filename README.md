# Password Generator Mini Project

This is a simple Java-based password generator. It allows the user to input various criteria for generating a secure password. The program offers the ability to select password length, inclusion of uppercase letters, lowercase letters, digits, and symbols.

## Features

- Customizable password length between 8 and 15 characters.
- Option to include uppercase letters, lowercase letters, digits, and symbols.
- Generates a strong, medium, or weak password based on the length and character types chosen.
- Shuffles the characters to create a randomized password.

## Requirements

- Java 8 or higher
